# Acordia

App para ensayar las canciones del coro: se trae la letra con acordes
(pegando texto o leyendo fotos), se cambia al tono del coro, se ajusta cuánto
dura cada acorde, se toca con piano para cantar encima y se exporta como foto o PDF.

**Abrir:** https://mesolano77.github.io/atril-ensayo/

## Instalar en el iPhone

1. Abre el enlace en **Safari**.
2. Toca **Compartir** (cuadrito con flecha hacia arriba).
3. Toca **Agregar a pantalla de inicio** → **Agregar**.

Queda un ícono **Acordia** que abre a pantalla completa. No necesita cuenta.
Después de abrirla una vez con internet, funciona sin conexión.
Las canciones se guardan solo en ese teléfono.

*Acordia* junta *acorde* y *concordia*: las dos vienen del latín *cor, cordis*
(corazón). Voces y corazones de acuerdo.

Este repositorio contiene solo la app ya construida. No incluye letras de
